    Section 1.1 Propositions

    Mathematics and logic deal with statements that are either true or false.
    🔗

    Definition 1.1.1.

    A mathematical statement or proposition is a statement that can be proven to be true or false.
    🔗
    🔗
    We start with some examples.
    🔗

    Example 1.1.2.

    Consider the following statements:
    1. \(1+2=3\text{.}\)
      🔗
      🔗
    2. An integer is divisible by two if and only if its last digit is \(0, 2, 4, 6\) or \(8\text{.}\)
      🔗
      🔗
    3. \(8^{2}=60\text{.}\)
      🔗
      🔗
    4. \(2^{8}<210\text{.}\)
      🔗
      🔗
    5. \(1>2\text{.}\)
      🔗
      🔗
    These are mathematical statements as each of them is either true or false. The first and the second statements above are true and the last two are false.
    🔗
    🔗

    Example 1.1.3.

    We give now some examples which are not propositions.
    1. Lebron James is a better basketball player than Michael Jordan.
      🔗
      🔗
    2. Messi is better than CR7.
      🔗
      🔗
    3. Taylor Swift is the greatest singer of all times.
      🔗
      🔗
    All the sentences above are opinions and cannot be proven using logic to be true or false.
    🔗
    Consider the following statements.
    1. Lebron James has scored more points in his NBA regular career than Michael Jordan.
      🔗
      🔗
    2. As of 2026, Michael Jordan has won more NBA titles than Lebron James.
      🔗
      🔗
    3. As of 2026, CR7 has scored more goals than Messi.
      🔗
      🔗
    4. Messi has won more World Cups than CR7.
      🔗
      🔗
    🔗
    The first statement above is true as Lebron James has scored \(43440\) points in his NBA regular seasons career while Michael Jordan has scored \(32292\) points.
    🔗
    The second statement is also true as Michael Jordan has won six NBA titles while Lebron James has won four such titles.
    🔗
    For the third statement, at the time of writing this book, CR7 has scored \(976\) goals while Messi has scored \(921\) goals. Hence, the third statement is also true.
    🔗
    The fourth statement is also true because Messi has won one World Cup in 2022 while CR7 has won none.
    🔗
    🔗
    Statements are usually represented by letters, for example, \(p, q, r\text{,}\) etc and the truth value true is represented by \(T\) and false is represented by \(F\text{.}\) Similar to common language where we can form complex sentences, in the logical statement, we can also form a compound statement by logical operators.
    🔗
    We use truth tables to describe the relationships between the truth values of propositions. The simplest truth tables are below.
    🔗
    \(p\)
    T
    F
    🔗
    and
    🔗
    \(p\) \(q\)
    T T
    T F
    F T
    F F
    🔗

    Definition 1.1.4.

    The negation of a proposition \(p\text{,}\) denoted by \(\neg p\) or not \(p\text{,}\) is true when \(p\) is false, and is false when \(p\) is true.
    🔗
    🔗

    Example 1.1.5.

    The negation of the proposition ``4 is an even number’’ is ``4 is not an even number’’ or ’’it is not the case that 4 is an even number’’.
    🔗
    The negation of the proposition ``this car is blue’’ is be the proposition ``this car is not blue’’.
    🔗
    🔗
    The following truth table summarizes the truth values for the negation.
    🔗
    \(p\) \(\neg p\)
    T F
    F T
    🔗

    Definition 1.1.6.

    Let \(p\) and \(q\) be two propositions. The proposition \(p\) and \(q\text{,}\) also denoted by \(p\wedge q\text{,}\) is true precisely when both \(p\) and \(q\) are true.
    🔗
    🔗

    Example 1.1.7.

    The proposition ``Delaware is the second smallest state in the United States and Dover is its capital’’ is true as each of the statements ``Delaware is the second smallest state in the United States’’ and ``Dover is its capital’’ is true.
    🔗
    The proposition `` \(1+3 =4\) and \(5>8\) ’’ is false because the proposition `` \(5>8\) ’’ is false .
    🔗
    🔗
    The truth table below summarizes the truth values for \(p\wedge q\) with all possible truth values of \(p\) and \(q\text{.}\)
    🔗
    \(p\) \(q\) \(p\wedge q\)
    T T T
    T F F
    F T F
    F F F
    🔗
    In conclusion, the statement \(p \wedge q\) is true if both \(p\) and \(q\) are true and false if at least one of the statements \(p\) or \(q\) is false.
    🔗

    Example 1.1.8.

    Let \(p\) be the statement \em Alice has 2 erasers and \(q\) be the statement \em Alice has 4 pencils. The compound statement \(p\wedge q\) is \em Alice has 2 erasers and 4 pencils.
    🔗
    🔗
    • Disjunction (OR) \(\vee\) When two statements are related by a disjunction, we denote it by \(p\vee q\) and read as `` \(p\) or \(q\) ’’. In this context, the ’’or’’ statement can sound a bit different from the ’’or’’ that we use in the daily life. If you are asked to choose a slice of cake or a scoop of ice cream, usually it means you can only pick one of them, but not both. However, in disjunction, choosing both is still considered true.
      🔗

      Example 1.1.9.

      Let \(p\) be the statement ``Alice gets 2 erasers’ and \(q\) be the statement ``Alice gets 4 pencils’’, the compound statement formed by disjunction will be ``Alice gets 2 erasers or 4 pencils.’’ If the reality is Alice gets either 2 erasers or 4 pencils, then the compound statement is true. The statement is only false if Alice doesn’t get 2 erasers and 4 pencils.
      🔗
      🔗
      The following truth table summarizes the truth values for the disjunction with all possible truth values of \(p\) and \(q\text{.}\)
      🔗
      \(p\) \(q\) \(p\vee q\)
      T T T
      T F T
      F T T
      F F F
      🔗
      In conclusion, a disjunction statement \(p\vee q\) is true if \(p\) is true or \(q\) is true or both \(p\) and \(q\) are true. It is false when both \(p\) and \(q\) are false. Furthermore, the type of ’’or’’ that we used in daily life is called an ’’exclusive or’’ in logic, where the statement is true only when one of them is true but not both.
      🔗

      Example 1.1.10.

      The compound statement `` \(2^{2}=6\) or \(5<6\) ’’ is true while the statement `` \(8\) is an odd number or \(8\) is divisible by 3’’ is a false statement.
      🔗
      🔗
      🔗
    • Implication/conditional proposition \(p\rightarrow q\) Can be read as: \(p\) implies \(q\), if \(p\) then \(q\), \(q\) is necessary for \(p\text{,}\) and \(p\) is sufficient for \(q\text{.}\) We can also say: \(p\) is the hypothesis and \(q\) is the conclusion.
      🔗
      Let \(p\text{:}\) ’’The husband gets bonus’’ and \(q\text{:}\) ’’He buys a gift for his wife’’. Then the implication \(p\rightarrow q\) is read as ’’if the husband gets bonus, then he buys a gift for his wife’’. Imagine if a person promises to get his wife a gift when he gets bonus, this promise is only broken if he gets bonus but not buying any gift. Otherwise, it is OK.
      🔗
      The following truth table summarizes the truth values for the implication with all possible truth values of \(p\) and \(q\text{.}\)
      🔗
      \(p\) \(q\) \(p\rightarrow q\)
      T T T
      T F F
      F T T
      F F T
      🔗
      Converse Given an implication \(p\rightarrow q\text{,}\) we can consider its converse which is \(q\rightarrow p\text{.}\)
      🔗
      The following table compares the truth values of an implication and its converse.
      🔗
      \(p\) \(q\) \(p\rightarrow q\) \(q \rightarrow p\)
      T T T T
      T F F T
      F T T F
      F F T T
      🔗
      An implication and its converse do not share the exact same truth value. This is a very important thing to note that whenever an implication is true, it does not directly imply that its converse is true. In the context of Mathematics, sometimes when a result is proven as an implication, mathematician will determine whether its converse is also true.
      🔗

      Example 1.1.11.

      Let \(x\) be a real number. Consider the statement: If \(x>0\) then \(x^{2}>0\text{.}\) This is a true statement since the square of a positive real number is a real number. However, its converse, which is if \(x^{2}>0\) then \(x>0\) is not true. Take \(x=-3\) for example, then the value of \(x^{2}=9 >0\) but \(x<0\text{.}\)
      🔗
      🔗
      In the situation where an implication and its converse are true, usually the result is presented as a double implication, which will be elaborated later in this section.
      🔗
      Besides the converse, we also consider the contrapositive of an implication.
      🔗
      Contrapositive If the implication is given by \(p\rightarrow q\) then its contrapositive is given by the implication \((\neg q) \rightarrow (\neg p)\text{.}\)
      🔗
      The following table compares the truth values of an implication and its contrapositive.
      🔗
      \(p\) \(q\) \(\neg p\) \(\neg q\) \(p\rightarrow q\) \(\neg q \rightarrow \neg p\)
      T T F F T T
      T F F T F F
      F T T F T T
      F F T T T T
      🔗
      Since these two compound statements share the same truth value, we can say that they are equivalent. This fact will be useful in the next chapter when we are writing proof. Example: If I get a C- then I pass this course. This is equivalent as saying, ``if I do not pass this course, then I do not get a C-’’.
      🔗
      🔗
    • Double implication \(p \Leftrightarrow q\) ( \(p\) if and only if \(q\) ) It means \(p\rightarrow q\) AND \(q\rightarrow p\)
      🔗
      \(p\Leftrightarrow q\)
      \(p\) \(q\) \(p\rightarrow q\) \(q \rightarrow p\) \((p\rightarrow q) \wedge (q\rightarrow p)\)
      T T T T T
      T F F T F
      F T T F F
      F F T T T
      🔗
      Conclusion: The double implication \(p\Leftrightarrow q\) is true if both \(p\) and \(q\) have the same truth value and it is false if \(p\) and \(q\) have different truth values.
      🔗
      Example:
      1. ``An integer \(x\) is an even number if and only if \(x\) is evenly divisible by 2,’’ is a true statement.
        🔗
        🔗
      2. ``A two digits number is even if and only if it ends with \(0\text{,}\)’’ is a false statement.
        🔗
        🔗
      🔗
      🔗
